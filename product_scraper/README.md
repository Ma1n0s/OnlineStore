# Product Scraper с использованием Claude AI

Этот скрипт использует бесплатный Claude AI для интеллектуального сбора данных о товарах из интернета.

## Возможности

- Автоматический сбор характеристик товаров
- Поиск изображений товаров
- Анализ цен (если доступно)
- Извлечение ключевых особенностей
- Сохранение результатов в JSON формате

## Установка

1. Клонируйте репозиторий:

```bash
git clone [repository-url]
cd product_scraper
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Установите Chrome браузер (если еще не установлен)

## Подготовка

1. Создайте аккаунт на Claude.ai (если еще нет)

2. Создайте файл `products.csv` со списком товаров:

```csv
product_name
Товар 1
Товар 2
...
```

## Использование

1. При первом запуске скрипта откроется окно браузера:

   - Войдите в свой аккаунт Claude.ai
   - После входа скрипт продолжит работу автоматически

2. Запустите скрипт:

```bash
python product_scraper.py
```

Результаты будут сохранены в файл `results.json`.

## Структура результатов

```json
[
  {
    "product_name": "Название товара",
    "analysis": {
      "specifications": [...],
      "image_urls": [...],
      "price_range": "...",
      "key_features": [...]
    }
  }
]
```

## Примечания

- Скрипт использует Selenium в headless режиме для скрапинга
- Встроена защита от блокировки (паузы между запросами)
- Промежуточные результаты сохраняются после каждого товара
- Используется логирование для отслеживания процесса
- Требуется только бесплатный аккаунт на Claude.ai
